# VAYNEX

VAYNEX is a personal charting terminal for gold and bitcoin: candles, footprint,
heatmap/DOM, volume profiles and options open-interest zones.

It reads live prices and price history from the user's own broker accounts to draw
charts. It does not place trades.

Built on the open-source Flowsurface project (GPL-3.0).
